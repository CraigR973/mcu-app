# Five-image photo hero v1 — source manifest

The primary photographic hero at `logo-system/hero-photo-five-v3.png` uses five
source photographs: one film or person per letter. It is a deterministic composite,
so the people and film artwork in the final master come directly from the files listed
below rather than from generated likenesses.

The original-resolution working files are stored in
`source-images/photo-logo-five-v1/`. The source-faithful composite is generated by
`logo-system/build_photo_hero.py`; the separate
`marks-cinematic-universe-five-image-art-direction.png` is a generative art-direction
study and is not the production master.
