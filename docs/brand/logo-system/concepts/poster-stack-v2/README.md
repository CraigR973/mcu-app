# Three-case + disc mark — corrected prototypes

> Selected direction: this exploration became the responsive production family in [`../../stack-family/README.md`](../../stack-family/README.md).

Corrected development of the direction Craig identified as the intended catalogue-frame concept: three overlapping physical movie cases with a partially visible disc. Internally this folder uses `poster-stack` to distinguish it from the six-cell grid experiment.

## Variants

- `poster-stack-reference.png` — the original concept supplied as the composition reference.
- `poster-stack-actual-posters-v1.png` — authentic poster crops for *Jaws*, *Double Indemnity*, and *An American Werewolf in London*.
- `poster-stack-concept-art-v1.png` — original, text-free illustrations evoking the same ocean-suspense, film-noir, and London-werewolf genres.
- `poster-stack-comparison.png` — the three large versions side by side.
- `poster-stack-small-size-test.png` — direct 128, 64 and 32 px reductions of both new prototypes.

## Shared design rules

- Preserve the three rising case peaks and central valley so the overall silhouette suggests an `M`.
- Keep the central burgundy case dominant.
- Keep one optical disc visible behind the right-hand case to establish physical ownership.
- Use champagne-gold case outlines, near-black borders/background, and restrained burgundy.
- Crop toward bold imagery and faces; avoid miniature credit text.

## Findings

- This direction communicates a personal physical movie collection more directly than the six-cell film grid.
- The authentic-poster version has the strongest emotional recognition and connects naturally to the photographic hero logo.
- The concept-art version is more cohesive, more ownable, and avoids dependence on licensed poster art.
- Both work strongly at 128 px, remain recognisable as a case collection at 64 px, and simplify to a coloured three-panel silhouette at 32 px. A dedicated flat micro mark would still be required for favicon use.

## Image-generation brief

The authentic-poster prompt preserved the reference geometry and replaced only the three internal cover artworks with faithful source crops. The concept-art prompt kept the same geometry and replaced those crops with original, text-free mid-century screen-print illustrations without actor likenesses.

Both were created with the built-in image-generation editor and saved non-destructively as new prototypes.
